## whisper.cpp and Whisper model weights

Server-side speech recognition uses `ggml-org/whisper.cpp` v1.8.3 and a
quantized multilingual Whisper Small model. The whisper.cpp code and the
original OpenAI Whisper code and model weights are available under the MIT
License:

- <https://github.com/ggml-org/whisper.cpp>
